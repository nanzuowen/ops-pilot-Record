# MySQL 慢查询

## 现象

服务接口响应时间升高，同时数据库查询耗时明显增加。

日志中可能出现：

- slow query
- query timeout
- SQL execution time too long
- JDBC timeout

数据库连接通常仍然可用，但部分 SQL 执行时间很长。

## 排查

1. 查看数据库查询延迟和接口响应时间。
2. 搜索慢 SQL 日志。
3. 找到执行时间较长的 SQL。
4. 使用 EXPLAIN 检查执行计划。
5. 检查是否存在全表扫描、索引缺失、索引失效。
6. 检查数据库锁等待情况。

## 判断

如果接口延迟升高，同时存在明显的慢 SQL，并且数据库连接正常，则优先判断为 MySQL 慢查询问题。

## 处理

根据执行计划进行优化：

- 增加合适索引
- 优化 SQL
- 减少扫描数据量
- 避免不必要的复杂查询
- 检查锁竞争

不要首先通过增加数据库连接池掩盖慢 SQL。
